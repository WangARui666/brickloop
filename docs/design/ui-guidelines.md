# Brickloop 界面设计规范

所有界面任务必须遵守本规范。主窗口按第 10 节清单看截图评审，不符合的退回修改。规范本身由主窗口维护，实现者不要自行改动。

## 1. 气质

专业、安静、以模型为中心。界面是深色中性灰，把视觉焦点留给 3D 视口里的彩色积木；只有一个强调色（暖橙）用来标示"当前/选中/主操作"。参考对象：专业 3D 与设计工具（Blender、Figma 暗色、Studio 的信息密度），但更干净、留白更讲究。

不要：大面积彩色块、渐变按钮、阴影堆叠、圆角过大的"卡片风"、emoji、花哨动画、默认 Ant Design 蓝。

## 2. 颜色令牌

全部颜色通过 CSS 变量（`--bl-*`）和 Ant Design 主题令牌使用，组件中不得写死颜色值（视口内积木颜色、连接点颜色除外）。

## 3. 字体与文字

- 字体栈：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif`。不打包字体文件。
- 基础字号 13px，行高 20px；小字 12px / 18px（状态栏、提示、次要信息）；面板标题 13px 半粗（600）；对话框标题 15px 半粗。全界面不超过 4 种字号。
- 数字（坐标、尺寸、数量）使用 `font-variant-numeric: tabular-nums`。
- 文案：简体中文，简短直接，用动词开头的操作名（"新建""导出 BOM"）。**界面上不得出现开发术语**：里程碑代号（M1、M0-3、P2）、"将在后续版本提供"、"TODO"、英文占位。未实现功能的按钮隐藏，或禁用并在提示中写"暂未开放"。
- 快捷键显示格式：`Ctrl+Shift+S`，提示中名称与快捷键之间留空，快捷键用次要文字颜色。

## 4. 间距、尺寸、圆角

- 4px 网格：间距只用 4 / 8 / 12 / 16 / 24 / 32。
- 控件高度：标准 28px，紧凑 24px（树、列表行），大号 32px（对话框主按钮）。
- 圆角：控件 6px，弹层与对话框 8px，零件缩略图 6px。不使用 > 8px 的圆角。
- 阴影：只用于浮层（菜单、下拉、对话框）：`0 8px 24px rgba(0,0,0,0.45)`；面板不加阴影，用 1px 边框分隔。
- 图标：lucide-react，16px，描边 1.75；工具栏图标 18px。不混用其他图标库。

## 5. 布局

```
┌ 菜单栏 32px ───────────────────────────────────────────────────────┐
├ 工具栏 40px ───────────────────────────────────────────────────────┤
├ 左栏 280px ┬──────────────── 视口 ─────────────────┬ 右栏 320px ──┤
│            │                                        │              │
├────────────┴────────────────────────────────────────┴──────────────┤
└ 状态栏 26px ───────────────────────────────────────────────────────┘
```

- 菜单栏：应用内自绘，左侧 16px 应用标志（简洁的环形积木图形，暖橙）+ 菜单项；菜单项 28px 高、水平内边距 10px，悬停 `--bl-bg-raised`。
- 工具栏：图标按钮 32×32，按组排列，组间 1px×20px 分隔线、左右各 8px 间距；当前工具底色 `--bl-accent-soft`、图标 `--bl-accent`；开关类（碰撞、吸附、连接点显示）开启时同样样式。每个按钮有提示：名称 + 快捷键。网格档位用紧凑下拉（显示"1 格 / ½ 格 / ¼ 格"）。工具栏右端放 AI 按钮（图标 + "AI 助手"文字，强调色描边）。
- 左右栏宽度可拖动调整（左 220–420，右 260–480），可折叠；折叠后保留 28px 宽的竖条，点击展开。拖动手柄悬停时显示 2px 强调色线。
- 面板头 36px：标题左对齐，操作图标右对齐；面板内容内边距 12px。
- 右栏用分段标签切换：色板 / 结构 / AI 助手。
- 视口占满剩余空间，无边框；视口内浮层（视角立方体、坐标轴、提示）离边缘 12px。
- 状态栏：12px 次要文字，项之间用 `·` 分隔（三级文字颜色），右侧显示网格档位与最后恢复点。

## 6. 组件规则

- 按钮：主按钮强调色实底、文字 `#1A1206`（深色字保证对比）；次按钮 `--bl-bg-surface` 底 + `--bl-border-strong` 边；文字按钮无底。每个视图最多一个主按钮。
- 输入框：`--bl-bg-surface` 底，1px `--bl-border-strong` 边，聚焦时边为强调色并加焦点环。搜索框左侧放搜索图标，右侧清除按钮。
- 树与列表：行高 24px，缩进 16px，悬停 `--bl-bg-raised`，选中 `--bl-accent-soft` 底 + 左侧 2px 强调色条；眼睛（隐藏）图标悬停时才显示，隐藏状态常显并降为三级文字色。
- 零件缩略图网格：方形格 76px，图片区 64px，名称两行省略（12px），悬停边框 `--bl-border-strong`，选中边框强调色；格间距 8px。
- 色块：24×24，圆角 4px，透明色用棋盘格底；当前色外圈 2px 强调色；悬停显示"乐高色名 · 工厂色号"。
- 标签页/分段控件：高 28px，当前项 `--bl-bg-active` 底、主文字色；不使用默认蓝色下划线。
- 提示（Tooltip）：`--bl-bg-raised` 底，12px，延迟 400ms。
- 空状态：居中的 32px 线性图标（三级文字色）+ 一行说明（次要文字）+ 可选的一个操作按钮。
- 对话框：宽 480/640，标题 15px，内容区 16px 内边距，按钮右对齐（取消在左、确认在右）。
- 滚动条：6px 宽，`--bl-border-strong` 滑块，悬停加深，轨道透明。

## 7. 视口视觉

- 背景：`--bl-viewport-top` → `--bl-viewport-bottom` 的竖向渐变。
- 地面网格：每格细线 `#262A33`（不透明度 0.6），每 8 格粗线 `#323844`；原点处 X 轴线红 `#E5534B`、Z 轴线蓝 `#4D8DFF`，不透明度 0.7；网格向远处淡出。
- 灯光：半球光 + 一盏主方向光（左上前方）+ 弱补光；后续加入柔和阴影。积木材质略带塑料光泽（低粗糙度、无金属度），边线为深色细线（随颜色变化的 LDraw 边线色）。
- 选中：外描边 2px 强调色；悬停：外描边 1px 白色 50%。
- 坐标轴指示与视角立方体在右下角，半透明面板底。
- 连接点显示沿用设计师配色（见 `docs/spec/05-connectivity.md` §1），只在视口中使用这些颜色。

## 8. 交互与动效

- 悬停/按下过渡 120ms ease-out；面板折叠 160ms；不做弹跳、缩放动画。
- 所有可点击元素有可见的键盘焦点环。
- 长操作（导入、AI 任务）显示进度与可取消按钮，不使用全屏遮罩阻断视口。

## 9. Ant Design 主题映射

`ConfigProvider` 使用 `theme.darkAlgorithm`，并覆盖：`colorPrimary=#FF8A3D`、`colorBgBase=#121418`、`colorBgContainer=#1F232B`、`colorBgElevated=#272C36`、`colorBorder=#3A4150`、`colorBorderSecondary=#2A2F39`、`colorText=#E7E9EE`、`colorTextSecondary=#A3ABBA`、`colorTextTertiary=#6E7686`、`borderRadius=6`、`fontSize=13`、`controlHeight=28`、`fontFamily` 同第 3 节；`colorTextLightSolid=#1A1206`（主按钮文字）。组件级覆盖（Menu、Tabs、Tree、Tooltip 等）集中在一个主题文件中，不在组件里零散写样式。

## 10. 评审清单（主窗口逐项检查截图）

1. 没有默认蓝色、没有写死颜色、只有一个强调色。
2. 没有开发术语或英文占位（中文界面下）。
3. 字号 ≤ 4 种，数字等宽，对齐到 4px 网格。
4. 工具栏图标统一（lucide、同尺寸同描边），分组清楚，当前状态可辨。
5. 面板标题、内边距、分隔线一致；无多余阴影与边框叠加。
6. 空状态有图标和一句话，不是大段说明。
7. 视口背景、网格、坐标轴符合第 7 节。
8. 1440×900 与 1100×700 两种窗口尺寸下无溢出、无文字截断错位。
