# 10 说明书

本章你将学会：将模型步骤导出为 PDF，选择纸张与每页步骤数，并核对重复子模型和零件用量。

说明书按模型中的步骤生成。PLI 是“本步零件清单”，列出当前步骤新加入的零件及数量；BOM 是整套模型的用量清单。两者用途不同，不要把每一步的累计画面当成本步用料。

## 导出前整理步骤

1. 在“结构”的步骤视图中整理搭建顺序，把每次需要新增的零件分到对应步骤，具体操作见[第 11 章](11-宏与搭建步骤.md)。
2. 使用“视图 → 逐步查看”，逐步检查连接顺序，避免把需要提前插入的零件放到封闭结构之后。
3. 回到正常编辑，运行整个工程的检查，确认所用工厂包和颜色。
4. 保存 `.brkl`，作为这份说明书对应的模型版本。

## 选择版式并导出

1. 选择“文件 → 导出 → 说明书 PDF”。
2. 选择纸张：A4 竖版、A4 横版、A5 或 Letter。大跨度模型可先尝试 A4 横版。
3. 选择每页步骤数：1、2 或 4。零件多、遮挡复杂的步骤宜少放；每页步骤数是上限，子模型切换或清单续页可能使实际步数减少。
4. 选择是否包含封面和零件清单页，设置语言、根模型及 150／300 dpi 图像清晰度。选择某个子模型作为根模型，可单独导出它的搭建说明。默认勾选“用细描边标出本步新增零件”，可按需关闭。分辨率中的 dpi 表示每英寸的图像像素数；提高 dpi 会让步骤图更清晰、文件更大，不改变纸张和页面布局。
5. 点击“导出”，通过进度条查看已完成页数；生成期间可点击“取消”。全部页面生成成功后才出现保存位置选择，文件通过原子替换保存。生成失败或取消不会写入半成品，也不会覆盖已有文件。

## 阅读生成的页面

同一个主模型或子模型的整段步骤使用固定的等轴测方向和缩放，缩放按该模型完成后的大小确定。之前步骤和新增零件均保留真实颜色，新件默认加细金黄色描边；零件缩略图使用透明背景。

每个步骤页包含步骤号、累计模型画面、本步新增零件高亮、本步零件图片与数量，以及页码。零件清单太长时会出现“本步零件（续）”，继续列出同一步的用料。

重复子模型采用“单份构建＋×N”：先展示一份部件的搭法，再在使用处标数量，不重复打印每份的全部搭建过程。完整 BOM 仍按实际使用次数统计。

例如模型中有两把相同椅子，椅子的内部步骤只需说明一次；使用它们的步骤以“×2”表示数量。如果同一共享部件通过继承颜色显示成不同颜色，单份示意会采用首次出现的颜色，交付时仍需结合实际配色和总清单核对。

Brickloop 生成 PDF 后，请用本机 PDF 阅读器打开。应用内没有 PDF 阅读器；这里以页面构成说明和下方核对步骤代替外部阅读器截图。

## 交付前检查 PDF

1. 在 PDF 阅读器中逐页核对画面与清单，检查同一模型在相邻步骤中的零件大小保持一致，并确认封面、子模型页和最后的零件清单。
2. 选择步骤号、数量或页码文字，尝试复制或搜索。页面采用混合形式：步骤图和缩略图是图片，步骤号、数量、名称及页码是可选择文字。
3. 核对重复子模型的数量、颜色与最终用料。临时隐藏的零件仍属于模型，不能用隐藏来删减说明书用料。
4. 若某一步图太小，先减少每页步骤数；若只是图像模糊，再提高分辨率。排版调整不改变模型本身的步骤与零件归属。
5. 给 PDF 与 `.brkl` 使用相对应的版本名称；修改模型后重新生成说明书。
