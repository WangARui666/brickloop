## 先完成一个小模型

1. 启动 Brickloop，确认左侧“零件库”显示零件，当前数据包为“示例包”或已核实的工厂包。
2. 搜索 `3001`，双击零件进入放置预览，在中央视口单击放下。
3. 在右侧“色板”选择颜色，再放一件；按 Esc 结束放置。
4. 按 F7 查看检查结果；按 Ctrl+S 保存为 `.brkl` 工程。
5. 需要交给 Studio 时，选择“文件 → 导出 → Studio .io”，导出后阅读报告。

`.brkl` 保存完整工程；`.io` 用于与 Studio 交换可编辑模型；`.brklpack` 是工厂零件和颜色资料；`.brklmacro` 是可复用的组合宏。示例包中的 `DEMO-` 编号仅用于演示，不能作为实际生产订单。

本说明对应 **0.12.6**，包含 68 张应用内截图。安装包在 GitHub 的 [Releases](https://github.com/WangARui666/brickloop/releases) 页面，各版本的变化见 [CHANGELOG](../../CHANGELOG.md)。
