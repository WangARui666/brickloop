# 附录：给工厂的数据包模板说明

本章你将学会：逐列填写工厂零件与颜色资料，准备自制件文件，并交回一套可检查、可更新的数据包。

这份附录可以直接交给工厂资料负责人。示例中的工厂编号、色号与包名称均为虚构演示，不代表订单或真实产能。

## 先确认交回哪些文件

| 文件              | 内容                                   | 是否需要                   |
| ----------------- | -------------------------------------- | -------------------------- |
| `pack.json`       | 这一批资料的名称、唯一编号、版本与来源 | 必须，通常由资料维护者填写 |
| `parts.xlsx`      | 工厂零件表                             | 必须                       |
| `colors.xlsx`     | 工厂色表                               | 必须                       |
| `categories.xlsx` | 工厂自己的分类树                       | 可选，由维护者提供格式     |
| `custom/`         | 自制件的形状文件及待转换原始资料       | 有自制件时按实际提供       |
| `images/`         | 零件照片、色卡照片等说明资料           | 可选                       |

1. 收到 `.brklpack` 后，用支持 ZIP 的解压软件打开；也可把副本改为 `.zip` 后解压。所有资料放在同一个目录。
2. 保留 XLSX 第 1 行中文表头和第 2 行灰色斜体说明，第 3 行起填写数据。不要合并数据单元格或把图片贴在编号栏。
3. 空白模板自带示例行，请替换或删除。更新已有资料时，明确核对保留、停产和新增项目。
4. 先填写 `colors.xlsx`，再填写 `parts.xlsx`。编号使用文本格式，保留 `0012` 这样的前导零。
5. 保存所有文件，交回完整目录；也可将目录内这些文件直接打包为 ZIP，再使用 `.brklpack` 扩展名。压缩包第一层应直接看到 `pack.json` 和两张表，不要额外套一层文件夹。

请在 Excel 中打开导出的 parts.xlsx，核对第 1 行字段名、第 2 行说明和第 3 行起的零件资料。此界面属于外部表格软件，本文以字段表和填写示例说明。

## 零件表 `parts.xlsx`

工作表名称为“零件”。一行填写一种零件，它能生产的多种颜色填在同一行。

| 列名       | 是否必填             | 请填写什么                                                                                                         |
| ---------- | -------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 工厂编号   | 是                   | 工厂内部用于识别这件零件的唯一编号，如 `F-0001`。不要同号多行，也不要只用大小写区分两个编号                        |
| 乐高编号   | 有对应同款时必填     | 已确认的零件编号，如 `3001`。自制件留空；不要填写工厂编号或颜色编号                                                |
| LDraw 文件 | 编号有多个版本时必填 | 对应的形状文件名，如 `3001.dat`。印刷、模具版本不明确时请设计师或维护者协助确认，不要猜文件名                      |
| 自制件编号 | 自制件必填           | 自制零件的稳定编号，如 `CUSTOM-001`，只用英文字母、数字、下划线或短横线。与“乐高编号”二选一，不能同时填            |
| 名称       | 是                   | 工厂使用的中文名称，如“砖 2×4”。软件优先显示这个名称                                                               |
| 分类       | 否                   | 分类 ID 或中文分类名，如“砖”。有分类表时必须能在表中找到；没有时可保留工厂自己的分类标识                           |
| 可产颜色   | 是                   | 填工厂色号，如 `F-RED,F-BLACK`，多个用逗号分隔。每个色号必须先存在于色表；不要填“红色”“全部”或没有核实的色号       |
| 状态       | 否                   | 下拉选择“在产”“停产”“待确认”，空白默认在产。停产件不作为可用工厂件；待确认件仍可被软件列为工厂件，生产前需另行核实 |
| 备注       | 否                   | 模具差异、需要补资料的内容等。备注不会自动改变可生产配色或检查规则                                                 |

填写示例：工厂编号 `F-0001`，乐高编号 `3001`，LDraw 文件 `3001.dat`，自制件编号留空，名称“砖 2×4”，可产颜色 `F-RED`，状态“在产”。

`parts.xlsx` 中的“颜色列表”页帮助选择单个色号。多色直接在“可产颜色”输入逗号分隔列表；导入时以 `colors.xlsx` 的真实内容为准。新加色号没有出现在辅助下拉中时，不要因此改成错误的旧色号。

同一个标准零件不能用两个工厂编号重复映射；确有不同模具或印刷版本时，请维护者确认能分别识别的文件。不同颜色的同一零件，也不要拆成重复零件行。

## 色表 `colors.xlsx`

工作表名称为“颜色”。每行定义一种工厂颜色。

| 列名        | 是否必填         | 请填写什么                                                                                                                            |
| ----------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 工厂色号    | 是               | 工厂内部唯一色号，如 `F-RED`。保持长期稳定，不要只用大小写区分                                                                        |
| 乐高色名    | 有准确对应时必填 | 已核实的标准英文色名，例如 `Bright Red`。不要凭肉眼近似随便套用；无对应色留空，由软件作为工厂独有色记录                               |
| 乐高颜色 ID | 否               | 与色名相符的非负整数。例如 `Bright Red` 对应 `21`；不是 LDraw 颜色码，不能填成 `4`。填 ID 时必须同时填正确色名                        |
| 中文名      | 否               | 如“亮红”。空白时沿用软件名称或以色号显示                                                                                              |
| 实测颜色值  | 是               | `#RRGGBB` 格式，如 `#B40000`，由 `#` 和六位十六进制字符组成。按工厂认可的测量或色卡资料填写                                           |
| 材质        | 否               | 下拉选择实色、透明、金属、珠光、闪粉、橡胶、夜光；还支持镀铬、斑点。空白时沿用对应标准色，独有色默认实色                              |
| 透明度      | 否               | 0—1 的数字，1 表示完全不透明，0 表示完全透明。例如 0.5 表示半透明；不要填百分号。空白沿用标准色，透明独有色默认 0.5，其余独有色默认 1 |
| 备注        | 否               | 色卡来源、测量方式、批次或待核实内容                                                                                                  |

演示行：工厂色号 `F-RED`，乐高色名 `Bright Red`，乐高颜色 ID `21`，中文名“亮红”，实测颜色值 `#B40000`，材质“实色”，透明度 `1`。此颜色值仅作格式示例，正式资料应换成核实的数据。

请在 Excel 中打开导出的 colors.xlsx，按下表核对色号、RGB、材质和透明度；透明度取值范围为 0 至 1。本文使用字段说明代替外部表格软件截图。

同一个标准色在一个包中只能映射一次。若工厂两个色号实际颜色不同，不要都套用同一个标准色；请维护者确认是否作为不同工厂独有色处理。屏幕显示和塑料实物可能有差异，色值不能代替实物色卡与打样。

## 可选分类表 `categories.xlsx`

需要工厂自己的分类层级时，请资料维护者准备“分类”工作表，使用下列中文表头；第 3 行起填数据。

| 列名      | 是否必填 | 请填写什么                                        |
| --------- | -------- | ------------------------------------------------- |
| 分类 ID   | 是       | 分类的唯一代号，如 `bricks`，供零件表与子分类引用 |
| 中文名    | 是       | 显示名称，如“砖”                                  |
| 英文名    | 否       | 英文显示名称，如 `Bricks`                         |
| 父分类 ID | 否       | 上一级分类的 ID；最上层留空，不要填中文名或自己   |
| 顺序      | 否       | 整数排序值，空白为 0；按希望的顺序填写            |
| 图标      | 否       | 已约定的图标名称，不是图片文件路径；不清楚时留空  |

父分类必须已经列在表中，不能互相循环。例如“砖”不能属于“板”，同时“板”又属于“砖”。

## 包信息 `pack.json`

这部分通常由设计方的资料维护者完成，工厂提供名称、版本、日期和来源即可。包 ID 是整批资料的唯一编号；软件不会用同一 ID 覆盖旧包，新版也应取得新 ID。

| 字段              | 含义与填写方法                                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `id`              | 唯一包 ID，1—80 个字符，以英文字母或数字开头，只含英文字母、数字、下划线、短横线；不能用 Windows 保留名称。如 `factory-sample-202610` |
| `name`            | 软件显示名称，如“演示工厂资料 2026-10”，不能为空                                                                                      |
| `version`         | 资料版本，如 `1.0.0`，不能为空；更新版本仍需新 ID                                                                                     |
| `source`          | 工厂、色卡或资料来源说明，不能为空                                                                                                    |
| `createdAt`       | 有效日期时间，建议格式 `2026-10-16T00:00:00.000Z`                                                                                     |
| `templateVersion` | 模板格式版本，当前为数字 `1`，请保留                                                                                                  |
| `contentHash`     | 内容校验值。导出的可编辑模板为空字符串；正式入库时软件生成，不需要工厂计算                                                            |

```json
{
  "id": "factory-sample-202610",
  "name": "演示工厂资料 2026-10",
  "version": "1.0.0",
  "source": "虚构示例，请替换为实际资料来源",
  "createdAt": "2026-10-16T00:00:00.000Z",
  "templateVersion": 1,
  "contentHash": ""
}
```

更新正式数据包时，先从软件“导出模板”取得可编辑版本，再填写。直接修改已经封装并带校验值的正式包，会触发“内容哈希不匹配”；不要把删除校验值当成日常修复办法。

## 自制件和照片

1. 自制件使用“自制件编号”，对应 `.dat` 文件放在 `custom/`。填写“LDraw 文件”时必须提供那个真实文件。
2. 没填文件名时，软件会尝试查找 `custom/<自制件编号>.dat`；找不到会警告并保留占位资料。
3. 有 STL、STEP 等原始文件时也请提供，注明单位与尺寸，交维护者转换。保留原文件不意味着软件已经可以把它当作可用积木形状。
4. 照片放入 `images/`，建议文件名带工厂编号或色号。连接点、碰撞资料需维护者另行审核，照片不能自动替代这些资料。

## 交回前逐项核对

1. 检查所有必填列、中文表头和文件名；保持三份必需文件在同一目录。
2. 检查工厂编号和色号是否重复，零件表中的每个可产色号是否存在于色表。
3. 删除未使用的示例行，核实在产、停产和待确认状态；不要用备注代替状态列。
4. 确认这次资料的新包 ID 与来源说明，由设计师导入审阅。
5. 收到校验报告后，按文件、行号、列名修正。无法确认的编号、标准色映射和自制件文件，请明确说明缺什么，不要猜填。

导入、启用和回滚操作见[第 3 章](03-零件库与数据包.md)。
